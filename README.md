# GenericFramework
🔥 FastAPI 通用后端学习脚手架 | 开放共建
🔥 FastAPI General Backend Scaffold | Open for Co-construction

## 📖 项目简介 | Introduction
【中文】
本项目是轻量化 FastAPI 基础脚手架，定位**学习实践用途**。
内置分层目录结构、统一接口响应封装、JWT 鉴权工具、全局鉴权中间件、登录注册基础模块。
代码追求清晰易懂，适合学习 FastAPI、JWT 身份认证、中间件开发等知识点。

本仓库为共创项目，欢迎提交 Issue 交流思路、提交 PR 参与优化完善！

【English】
This is a lightweight FastAPI basic scaffold mainly for **learning & practice**.
It contains layered project structure, unified API response wrapper, JWT utility, global authentication middleware, login & register modules.

Codes are written for readability, suitable for learning FastAPI, JWT authentication, middleware development and related web knowledge.
This is an open co-building project. Feel free to open issues for discussion or submit PRs for improvements.

## ✨ 内置功能 | Features
- FastAPI 分层工程结构 Layered FastAPI project structure
- 标准化统一返回格式 Standardized unified API response
- JWT 生成、解析工具 JWT encode & decode utilities
- 全局鉴权中间件（支持接口白名单）Global auth middleware with whitelist support
- 路由依赖式鉴权（可选方案）Route dependency authentication (alternative option)
- 基础登录、注册请求模型 Basic login & register request schema
- 全局日志封装 Global log wrapper
